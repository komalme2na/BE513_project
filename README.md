## Projects

### 1. Quick BED Sort
Merges gzipped BED files, filters chromosomes using a selection file, and sorts genomic records according to the specified chromosome order.

**Technologies:** Python, Bash, AWK, GNU Sort

### 2. Rescale to Reference
Rescales genomic fragment distributions to match a target reference histogram and evaluates the distribution using Total Variation distance.

**Technologies:** Python, NumPy, Matplotlib

### 3. V-Plot
Generates V-plots from genomic fragment data to investigate fragment-length and positional patterns.

**Technologies:** Python, NumPy, Matplotlib

### 4. TCGA RNA-seq Analysis
Analyzes NKX2-1 gene expression in TCGA-LUAD tumour and normal samples, including matched-patient statistical analysis and visualization.

**Technologies:** Python, R, TCGA data
